# Shiraz Website

A static website for Shiraz (`shiraz.ir`).

## Structure

- `main_page.html` — main page
- `pages/` — additional pages
- `styles/` — stylesheets
- `scripts/` — client-side scripts
- `images/`, `fonts/` — static assets

## Run

Open `main_page.html` in a browser, or serve the directory with any static
file server:

```bash
python -m http.server 8000
```
